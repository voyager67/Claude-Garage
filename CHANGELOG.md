## [Unreleased]
Complete first version.

### Added
- 13 specialist agents: chief, scout, pm, architect, pixel, rigger, builder, tester, gremlin, sentinel, critic, detective, scribe
- 20 slash commands covering setup, understanding, planning, building, verifying, shipping and maintaining
- Three lanes (S, M, L) chosen by `/pitch` and auto-detected by `/sprint`, with blind acceptance scenarios for size L
- Drift detection, code ownership for tests, adaptive review and adversarial debugging
- `.garage/` workspace with `rules.md` guardrails and `lessons.md` compounding memory
- Interactive commands: `/guide`, `/brainstorm`, `/rules`
- Output styles: Garage Rush and Garage Mentor
- Optional statusline and Agent Teams setup via an interactive installer
- Interactive GitHub Pages site and generated reference docs
- Validation script and CI workflow
