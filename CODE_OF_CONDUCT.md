# Code of Conduct

We want Claude Garage to be a friendly, productive place for everyone.

**Expected:** be respectful, assume good intent, give specific and kind feedback, and welcome newcomers.

**Not acceptable:** harassment, personal attacks, discrimination, trolling, or publishing others' private information.

Maintainers may edit, remove or reject contributions that violate this code and may restrict participation of anyone who does. Report concerns by opening a private security advisory on this repository or by contacting the maintainer through their GitHub profile.

This policy is inspired by widely used community standards and applies in all project spaces.
