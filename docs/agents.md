# Agent reference

_Generated by `scripts/build-docs.py`._

| Agent | Job | Tools |
|---|---|---|
| 📐 **architect** | Technical design. Use to turn a pitch into a blueprint with trade-offs, interfaces, file-level changes and small build slices. | `Read, Grep, Glob, Write` |
| 🔨 **builder** | Implementation. Use to build exactly one blueprint slice with tests first and the smallest correct diff. | `Read, Write, Edit, Grep, Glob, Bash` |
| 🧭 **chief** | Complexity assessment and routing. Use at the start of any piece of work to size it (S, M or L), pick the right lane and name which specialists should be involved. | `Read, Grep, Glob` |
| 🧐 **critic** | Code quality review. Use to check readability, duplication, naming, error handling and design drift against the blueprint. | `Read, Grep, Glob, Bash` |
| 🕵️ **detective** | Root-cause debugging. Use when something is broken and the cause is not obvious. Forms competing hypotheses and tries to disprove them. | `Read, Grep, Glob, Bash` |
| 👹 **gremlin** | Adversarial QA. Use to break new code with hostile inputs, edge cases, race conditions and bad state, and to prove each break with a failing test. | `Read, Write, Edit, Grep, Glob, Bash` |
| 🎨 **pixel** | UX, interaction design and accessibility. Use for any user-facing change: flows, screens, copy, empty and error states, keyboard and screen-reader support. | `Read, Grep, Glob, Write` |
| 🎯 **pm** | Product thinking. Use to sharpen scope, define the target user, write non-goals and success metrics, and cut features that do not earn their place. | `Read, Write, Grep, Glob` |
| 🏗️ **rigger** | Platform and delivery engineering. Use for CI/CD, containers, infrastructure as code, environment config, observability and anything that decides how the software runs in production. | `Read, Grep, Glob, Bash, Write, Edit` |
| 🔭 **scout** | Read-only codebase recon. Use proactively to find what already exists, how things are wired, and where conventions live before anyone designs or edits anything. | `Read, Grep, Glob, Bash` |
| ✍️ **scribe** | Documentation and release writing. Use for READMEs, changelogs, release notes, docstrings and architecture notes that match the code as it really is. | `Read, Write, Edit, Grep, Glob` |
| 🛡️ **sentinel** | Security review. Use on any change touching auth, user input, secrets, file access, network calls or dependencies. | `Read, Grep, Glob, Bash` |
| 🧪 **tester** | Test strategy and blind acceptance scenarios. Use to decide what to test, to write scenarios builders never see, and to find coverage gaps. | `Read, Write, Edit, Grep, Glob, Bash` |
